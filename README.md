# MetodosNumericos

Método de Gauss

Lenguaje de programación: El programa lo desarrollé con Java.

Compilación y ejecución:
1. Abrir el proyecto en un programa compatible con Java.
2. Ejecutar la clase "Lanzador_gaus".
3. El programa utilizará la matriz definida en la clase "defmatrizz".
4. Se mostrará en la consola el resultado de las soluciones del sistema de ecuaciones.

Ejemplo de prueba:
Matriz utilizada:
2.0, 1.0, -1.0, 8.0
-3.0, -1.0, 2.0, -11.0
-2.0, 1.0, 2.0, -3.0
Soluciones del sistema: 
x1 = 2.0
x2 = 3.0
x3 = -1.0
